Como conectar um tenant

Passos operacionais para ativar WhatsApp de um cliente — não é só o endpoint.

  1. Cadastre a aplicação mãe (Systems) e guarde a API Key exibida na criação.
  2. No SaaS, mint o state com POST /v1/embedded-signup/state (X-API-Key).
  3. Abra o Embedded Signup da Meta com esse state; o callback cria/atualiza a conexão no gateway.
  4. Alternativa: use + Nova conexão para cadastrar WABA, Phone Number ID e token manualmente.
